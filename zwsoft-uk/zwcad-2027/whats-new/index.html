What's new in ZWCAD 2027 Beta

New CAD tools for BIM handoff, data extraction, QA, and output.

The 2027 Beta update brings direct RVT import, model sectioning, smarter block placement, stronger data extraction, Xref display control, comparison improvements, and faster daily operations.

Top features

The headline upgrades buyers will ask about first.

The release notes, launch materials, demo script, and beta press material emphasize these upgrades for everyday CAD work.

New

RVT Import

Import Revit 2015-2025 RVT files directly into ZWCAD. Model entities, levels, grids, category data, families, instance data, levels, and material information can be converted for CAD-side management.

Use in BIM workflows
New

Section View

Create section boxes and section objects to inspect 3D model spaces. 3DSECTION supports dynamic bounding boxes, while PLANARSECTION supports custom section planes.

Enhanced

Data Extraction

Extract from multiple folders and drawings, include more object and attribute types, apply table styles and filters, and create linked extraction tables that can be updated.

New

Smart Merge

Arrange drawings horizontally or vertically, use standard and advanced merge modes, preview layouts, customize drawings per row or column, and improve roll paper output.

New

Xref Display

Apply color overrides and layer filters when attaching references, manage inserted references through XREFDISPLAY, and reuse imported or exported filtering rules.

Enhanced

Performance

Opening drawings, panning, zooming, copying, pasting, and moving improve by an average of 50%. Nested in-place editing improves by 150% in collaborative scenarios.

Data tools

Less manual counting, cleaner tables, faster delivery.

Data-heavy users have a clear reason to evaluate the beta: the release adds more ways to extract, link, measure, and report from DWG files.

Coordinate Extraction

Extract feature point coordinates from multiple objects in one operation, including block base points, circle centers, and vertices. Tables can be automatically numbered and sorted.

Measurement Table upgrades

Area Table now adds length tables and area-length tables. Users can select multiple objects and create summarized area, length, and area-length results.

MEASUREGEOM enhancement

Volume, total area, and total length queries are available without modifying the drawing, supporting fast checks during design and review.

Linked extraction tables

Extraction tables can be linked and updated, making summaries more reliable when drawings continue to change during delivery.

Drawing and collaboration

Daily drafting gets more automation without changing habits.

Many 2027 changes are intentionally practical: fewer repetitive commands, cleaner references, better comparison, and a calmer workspace.

Snap Align

Blocks or selection sets can automatically rotate and align with target object feature points. INSERT now includes a Snap Align option for faster placement.

File Compare and Object Compare

Comparison supports more object types, manual base point alignment, automatic base point alignment, and object comparison within the current drawing.

Online Map optimization

XYZ link services, map favorites, improved WMS and WMTS parsing, and a 50% map loading and refresh efficiency improvement support GIS-connected work.

Font substitution

Missing fonts can be replaced in one step with a unified substitute font. ZWCAD can remember selected replacements for future drawings.

Configuration migration

The redesigned migration workflow supports importing settings from older versions plus command-line and silent operations for import, export, backup, and reset.

DCL module optimization

DCL parsing, encoding support, high-DPI display, layout behavior, refresh performance, and debugging diagnostics have been improved for developers.
