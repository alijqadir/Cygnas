BIM to CAD workflows

Use Revit model context without moving every drafter into BIM authoring.

ZWCAD 2027 Beta is positioned as a BIM workflow companion: import RVT models, inspect sections, create 2D deliverables, manage references, and compare revisions in a familiar DWG environment.

Clear positioning

ZWCAD is a companion to BIM, not a Revit replacement.

The launch material is explicit on this point: Revit remains the 3D parametric modelling platform. ZWCAD 2027 Beta helps teams use model data in CAD workflows where the deliverable is still DWG-based drafting, detailing, review, or documentation.

  • Reduce expensive viewer-only or drafting-only BIM seat pressure.
  • Give CAD users access to useful model geometry and properties.
  • Create clearer 2D drafting outputs from upstream model context.
  • Keep DWG teams working in a familiar environment.
Workflow

A practical route from model to DWG deliverables.

For teams that care less about a feature list and more about delivery fit, start with the handoff they manage every week.

Import RVT files from Revit 2015-2025.

ZWCAD converts model entities and base entities such as levels and grids into block references while retaining useful visual attributes, categories, family data, level data, and material data.

Manage imported model context through layers.

Imported categories can be assigned into a clearer layer structure so CAD users can show, hide, review, and prepare drawing context more effectively.

Inspect internal details with section tools.

Use 3DSECTION for a dynamic section box or PLANARSECTION for section objects and custom display regions around model areas that matter.

Coordinate references without damaging source files.

Xref display rules can override colors or filter layers in the current drawing only. This helps teams standardize reference appearance without changing the original reference files.

Compare changes before issuing drawings.

File Compare, auto-align, manual base point alignment, and Object Compare help teams catch version differences before the drawing leaves the project team.
